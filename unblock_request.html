ข้อกำหนดเบื้องต้นก่อนยื่นคำร้องขอปลดล็อกห้อง OpenChat

1. กรณีโดนลบเพราะ ใส่เบอร์โทรในชื่อ / ใช้รูปโปรไฟล์การ์ตูน / ไม่ตั้งชื่อตามรูปแบบห้อง ต้องแก้ไขโปรไฟล์ให้ถูกต้องก่อนส่งคำร้อง
2. กรณีโดนบล็อกจากการโพสต์ผิดกติกาหรือถูกร้องเรียน ทีมผู้ดูแลจะตรวจสอบประวัติและติดต่อกลับทาง Line ID หรือ เบอร์โทรศัพท์ ที่ระบุไว้ภายใน 3–7 วันทำการ
